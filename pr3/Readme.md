# Практична робота №3

## Тема

**Написання тест-кейсів**

## Мета роботи

Закріпити знання з QA/QC та навчитися створювати зрозумілі, короткі й атомарні тест-кейси для перевірки якості програмного або технічного продукту.

---

## 1. Опис об'єкта тестування

Для тестування обрано **автоматичну кавомашину**.

Кавомашина призначена для приготування кавових напоїв. Користувач може вмикати та вимикати пристрій, наливати воду, засипати каву, запускати приготування напою та очищати контейнер для використаної кави.

Основні частини кавомашини:

* корпус;
* резервуар для води;
* контейнер для кавових зерен;
* кавомолка;
* заварювальний блок;
* носик для подачі кави;
* панель керування;
* контейнер для використаної кави;
* піддон для крапель;
* система нагрівання води.

Під час тестування перевіряється правильність роботи основних функцій кавомашини та її окремих компонентів.

---

## 2. Тест-кейси

### TC-01 — Увімкнення кавомашини

**Пріоритет:** Високий

**Передумови:** Кавомашина підключена до електромережі.

**Кроки:**

1. Натиснути кнопку увімкнення.
2. Дочекатися завершення запуску.

**Очікуваний результат:** Кавомашина вмикається та переходить у стан готовності до роботи.

**Фактичний результат:** Кавомашина увімкнулася та перейшла у стан готовності.

**Статус:** Pass

---

### TC-02 — Перевірка нагрівання води

**Пріоритет:** Високий

**Передумови:** Кавомашина увімкнена, резервуар заповнений водою.

**Кроки:**

1. Увімкнути кавомашину.
2. Дочекатися завершення нагрівання.

**Очікуваний результат:** Вода нагрівається, після чого кавомашина повідомляє про готовність до приготування кави.

**Фактичний результат:** Вода нагрілася, кавомашина готова до роботи.

**Статус:** Pass

---

### TC-03 — Приготування чашки кави

**Пріоритет:** Високий

**Передумови:** Кавомашина увімкнена, у резервуарі є вода та кава.

**Кроки:**

1. Поставити чашку під носик для подачі кави.
2. Обрати режим приготування кави.
3. Натиснути кнопку запуску.

**Очікуваний результат:** Кавомашина готує каву та подає напій у чашку.

**Фактичний результат:** Кава приготована та подана у чашку.

**Статус:** Pass

---

### TC-04 — Перевірка роботи кавомолки

**Пріоритет:** Високий

**Передумови:** У контейнері є кавові зерна.

**Кроки:**

1. Увімкнути приготування кави.
2. Дочекатися початку роботи кавомолки.

**Очікуваний результат:** Кавомолка подрібнює кавові зерна перед приготуванням напою.

**Фактичний результат:** Кавомолка працює та подрібнює зерна.

**Статус:** Pass

---

### TC-05 — Перевірка резервуара для води

**Пріоритет:** Високий

**Передумови:** Кавомашина вимкнена.

**Кроки:**

1. Вийняти резервуар для води.
2. Наповнити його водою.
3. Встановити резервуар назад у кавомашину.

**Очікуваний результат:** Резервуар встановлюється без проблем, кавомашина визначає його наявність.

**Фактичний результат:** Резервуар встановлений, кавомашина працює нормально.

**Статус:** Pass

---

### TC-06 — Перевірка роботи панелі керування

**Пріоритет:** Середній

**Передумови:** Кавомашина увімкнена.

**Кроки:**

1. Натиснути кнопку вибору напою.
2. Перевірити реакцію панелі керування.

**Очікуваний результат:** Натискання кнопки розпізнається кавомашиною та запускає відповідну функцію.

**Фактичний результат:** Панель керування реагує на натискання.

**Статус:** Pass

---

### TC-07 — Перевірка контейнера для використаної кави

**Пріоритет:** Середній

**Передумови:** Контейнер містить використану каву.

**Кроки:**

1. Вийняти контейнер.
2. Очистити його.
3. Встановити контейнер назад.

**Очікуваний результат:** Контейнер легко виймається, очищається та правильно встановлюється назад.

**Фактичний результат:** Контейнер очищений та встановлений на місце.

**Статус:** Pass

---

### TC-08 — Перевірка піддона для крапель

**Пріоритет:** Середній

**Передумови:** У піддоні є вода.

**Кроки:**

1. Вийняти піддон.
2. Вилити воду.
3. Встановити піддон назад.

**Очікуваний результат:** Піддон легко виймається та встановлюється назад без пошкоджень.

**Фактичний результат:** Піддон працює належним чином.

**Статус:** Pass

---

### TC-09 — Приготування кави без води

**Пріоритет:** Високий

**Передумови:** Резервуар для води порожній.

**Кроки:**

1. Увімкнути кавомашину.
2. Обрати приготування кави.
3. Натиснути кнопку запуску.

**Очікуваний результат:** Кавомашина не починає приготування та повідомляє про відсутність води.

**Фактичний результат:** Кавомашина не почала приготування та повідомила про необхідність долити воду.

**Статус:** Pass

---

### TC-10 — Перевірка автоматичного вимкнення

**Пріоритет:** Середній

**Передумови:** Кавомашина увімкнена та не використовується.

**Кроки:**

1. Не використовувати кавомашину протягом встановленого періоду часу.
2. Перевірити стан пристрою.

**Очікуваний результат:** Кавомашина автоматично переходить у режим очікування або вимикається відповідно до налаштувань.

**Фактичний результат:** Кавомашина перейшла в режим очікування.

**Статус:** Pass

---

## 3. Підсумок тестування

Було створено **10 тест-кейсів** для перевірки автоматичної кавомашини.

Під час тестування перевірено:

* увімкнення пристрою;
* нагрівання води;
* приготування кави;
* роботу кавомолки;
* резервуар для води;
* панель керування;
* контейнер для використаної кави;
* піддон для крапель;
* реакцію на відсутність води;
* автоматичне вимкнення.

Усі тест-кейси мають чіткі передумови, кроки, очікуваний та фактичний результат. Тест-кейси є окремими та перевіряють конкретні функції кавомашини.

# 4. Контрольні питання

### 1. Для чого потрібні тест-кейси?

Тест-кейси потрібні для перевірки роботи продукту. Вони описують, що саме потрібно перевірити, які дії виконати та який результат очікується.

### 2. Які основні атрибути тест-кейсу?

Основними атрибутами є:

* ID;
* назва;
* пріоритет;
* передумови;
* кроки виконання;
* очікуваний результат;
* фактичний результат;
* статус тестування.

### 3. Які бувають види тест-кейсів?

Тест-кейси можуть бути позитивними, негативними, функціональними, нефункціональними, регресійними та іншими залежно від того, що саме перевіряється.

### 4. Що таке негативний тест-кейс?

Негативний тест-кейс перевіряє поведінку системи у неправильній або непередбаченій ситуації. Наприклад, спроба приготувати каву, коли в резервуарі немає води.
